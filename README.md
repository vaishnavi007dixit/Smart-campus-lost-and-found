# smart-campus-lost-and-found
A web application that helps students report and find lost items on campus.

### Features
- Report lost items
- Report found items
- View all reported items
- Data stored using Firebase Firestore

### Tech Stack
- HTML
- CSS
- JavaScript
- Firebase (Firestore)

### How to Run
1. Clone the repository
2. Open index.html in a browser

### Google Technologies Used
- Firebase Firestore
